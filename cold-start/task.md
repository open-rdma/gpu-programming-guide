## 第一步，梳理课程大纲

### 梳理Cuda Programming Guide的内容

*使用plan mode进行本小结内容处理*

CUDA是一个复杂的技能，因此需要从完整的CUDA Programming Guide中找出适合教学的部分。此为，由于CUDA发展非常迅速，作为初期培训，不应引入过多先进的技术，而应该帮助学员学习CUDA编程的本质。

为此，当前目录下有两个版本的CUDA Programming Guide的网页存档，分别是：
* 旧版本，位于`Programming Guide __ CUDA Toolkit Documentation 11.5.1.html`
* 新版本，位于`CUDA C++ Programming Guide — CUDA C++ Programming Guide-13.0.html`
你需要对比并整理出新旧版本中共性内容，作为基础教学内容。同时整理出新版本中新增的内容，作为独立的章节，在学员掌握新基础知识后用于提升。即本教程以旧版本的为主，新版本为辅。

由于文档内容很大，很长，你需要启动若干个独立的Agent，对上述问题进行处理，避免上下文窗口爆炸。

### 为课程提供一个实验环境

需要开发一个可供多人提交的在线测评系统。该系统部署在一个具有NVIDIA 3060显卡的服务器上，运行在环境中，自带HTTP Server，通过HTTP Server接受提交。接受提交后，首先检测程序是否包含恶意代码，然后调用nvcc进行编译，调用ncu进行性能测评，然后提供NCU原始测评文件的下载接口，供用户下载后在本地的ncu可视化界面中查看结果。
* 需要有鉴权机制，只有授权用户可以提交。因此需要配备一个管理后台。
* 需要有速率限制，每个用户提交的频率有限制。
* 需要有一个排队机制，所有用户可以看到自己提交的代码正排在什么位置等待测评。
* 容器化部署，需要形成Dockerfile
