# 前言

欢迎来到GPU编程的世界！

随着人工智能、科学计算和数据处理的飞速发展，GPU（图形处理器）已经从单纯的图形渲染单元演变为强大的通用并行计算平台。NVIDIA CUDA 作为目前最成熟、应用最广泛的GPU编程框架，为开发者提供了在GPU上释放极致计算性能的能力。

然而，学习CUDA编程并非易事。CUDA Programming Guide是一份超过1000页的综合性技术文档，涵盖从编程模型、API参考到性能调优的方方面面。对于初学者来说，直接从这份技术手册入手往往感到无从下手——哪些是必须掌握的核心概念？哪些是适合在进阶阶段学习的内容？如何将理论知识转化为实际编码能力？

这正是本课程的切入点。

## 课程定位

<strong>本课程是为CUDA编程初学者设计的一本"有温度的导学手册"</strong>。我们的目标不是让你通读CUDA Programming Guide的每一页，而是帮助你：

1. <strong>建立CUDA编程的核心知识体系</strong>——理解线程层次结构、内存模型、异步执行、硬件架构这些基石概念
2. <strong>获得动手实践的能力</strong>——通过渐进式的矩阵乘法优化实验，亲身体验"从能运行到高性能"的完整过程
3. <strong>培养性能调优的思维</strong>——学会使用分析工具（NCU、Nsight）识别瓶颈，掌握合并访问、Bank Conflict、Occupancy等核心优化技术

## 内容来源

本课程的内容主要来源于：

- [NVIDIA CUDA C++ Programming Guide 11.5.1](https://docs.nvidia.com/cuda/archive/11.5.1/) —— 课程的核心参考，基础篇的大部分内容来自此版本
- [NVIDIA CUDA C++ Programming Guide 13.0](https://docs.nvidia.com/cuda/archive/13.0.3/cuda-c-programming-guide/) —— 进阶篇内容的主要来源
- [How to Optimize a CUDA Matmul Kernel for cuBLAS-like Performance: a Worklog](https://siboehm.com/articles/22/CUDA-MMM) —— 课程实验的设计蓝本
- Hello-Agents 开源课程 —— 课程的结构和写作风格参考

我们尽可能引用并重新组织了参考文档中的原文描述，将其翻译为中文后呈现给读者，而不是自行创造比喻或不准确的概念解释。

## 如何使用本课程

### 学习路径建议

<strong>如果你有NVIDIA GPU</strong>：

- 按章节顺序学习，每学完一章后立即运行对应的代码示例
- 每个实验都应亲手编写和调试代码，而不仅仅是阅读参考实现
- 使用NCU（NVIDIA Nsight Compute）分析你的实现与参考实现之间的性能差异

<strong>如果你暂时没有GPU</strong>：

- 你仍然可以学习CUDA编程模型、内存层次、性能优化策略等理论知识
- 建议在有条件时尽快上手实际操作——GPU编程的学习离不开动手实践
- 可以关注我们后续推出的在线评测平台，它提供远程GPU环境

### 章节结构

每章包含以下模块：

- <strong>学习目标</strong>——本章预期达成的学习成果
- <strong>正文讲解</strong>——概念、原理和代码示例
- <strong>动手体验</strong>——本章的实践环节
- <strong>本章小结</strong>——核心知识点的总结
- <strong>习题</strong>——从分析理解到动手实践的递进式练习
- <strong>参考文献</strong>——本章内容的原始出处

## 预备知识

在学习本课程前，你应该具备：

- C/C++ 编程基础（了解指针、函数、结构体和基本语法）
- 了解计算机的基本组成（CPU、内存、硬盘）

以下知识会有帮助但不是必须的：

- 计算机体系结构基础（缓存、流水线等概念）
- 操作系统基础（内存管理、进程/线程概念）
- 任何其他并行编程模型的经验（OpenMP、MPI等）

## 硬件要求

本课程的基础篇（第1-11章）内容适用于 Compute Capability 3.5+ 的 NVIDIA GPU（即Kepler架构及更新）。实验和进阶部分需要：

- 基础实验：Compute Capability 6.0+（Pascal架构+）
- 进阶篇内容：Compute Capability 7.0 ~ 10.0（具体见各章节说明）

课程中的代码示例和实验默认以 <strong>RTX 3060 (sm_86)</strong> 为目标平台编译，如果你使用不同架构的GPU，请相应修改 `-arch` 编译选项。
